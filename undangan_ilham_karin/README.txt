SEBELUM DIPUBLIKASIKAN:
1. Ganti tautan RSVP contoh https://forms.google.com/ di index.html dengan link Google Form milik Anda.
2. Lagu Beautiful in White memiliki hak cipta. Memiliki file MP3 tidak otomatis memberi izin untuk memublikasikannya di website; pastikan Anda memiliki izin yang sesuai sebelum mengunggah website ke internet.
3. Unggah semua file dalam folder ini ke repository GitHub Anda, lalu aktifkan Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Musik dirancang mulai setelah pengunjung menekan tombol Buka Undangan karena browser biasanya memblokir autoplay.
